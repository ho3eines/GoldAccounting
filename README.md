# طلایار 🪙⚖️ — حسابداری طلافروشی

![طلایار](docs/banner.png)

اپلیکیشن اندرویدی **حسابداری کامل طلافروشی** — کاملاً **فارسی و راست‌به‌چپ**، با ظاهری مدرن و لوکس (تم تیره + طلایی)، و کاملاً **آفلاین**: همه‌چیز داخل خود گوشی ذخیره می‌شود و **هیچ سرور میانی نیست**. دریافت قیمت‌های بازار هم (در صورت تمایل) **مستقیم از خود گوشی** از یک API عمومی انجام می‌شود.

## ✨ امکانات

| بخش | توضیح |
|---|---|
| 🪙 **نرخ روز طلا** | ثبت نرخ روز گرم ۱۸عیار، معادل‌های خودکار (۲۴/۲۲/۲۱/۱۴ عیار و مثقال ۱۷)، تاریخچه و **نمودار روند نرخ** |
| 🧾 **فاکتور فروش** | اقلام از انبار یا دستی، محاسبهٔ خودکار طلا×نرخ روز، اجرت (٪ / تومان‌برگرم / ثابت)، سنگ و مزین، **مالیات ارزش افزوده روی اجرت**، تسویه نقدی + **طلای دریافتی از مشتری (با رسوب)** + مانده به حساب، اشتراک‌گذاری متن فاکتور، ابطال فاکتور با سند معکوس |
| 📦 **اجناس و انبار** | ثبت جنس (عیار، وزن، اجرت، سنگ)، کد/بارکد خودکار، موجودی/فروخته‌شده، ارزش روز هر جنس |
| ⚖️ **طلای آبشده/کارکرده** | موجودی بر اساس **گرم معادل ۱۸عیار**، خرید طلای کارکرده، ورود/خروج دستی، ارزش روز |
| 🛍️ **خرید طلای کارکرده** | نرخ پیشنهادی از روی نرخ روز و رسوب، پرداخت از صندوق یا به حساب مشتری |
| 👥 **مشتریان** | مانده نقدی و طلایی هر مشتری (بدهکار/بستانکار)، دفتر گردش حساب، دریافت وجه نقد یا طلا، تسویهٔ خودکار بدهی |
| 💰 **صندوق** | تراز لحظه‌ای، واریز/برداشت آزاد، همهٔ ورودی/خروجی‌های خودکار فاکتورها |
| 📊 **گزارش‌ها** | فروش امروز/ماه شمسی، اجرت دریافتی، مالیات جمع‌شده، ارزش روز موجودی، بدهی‌ها |
| 🗓️ **تقویم جلالی** | تاریخ‌ها کاملاً شمسی |
| 🔢 **اعداد فارسی** | نمایش و ورود اعداد فارسی با جداکنندهٔ هزارگان |
| 💾 **پشتیبان‌گیری** | خروجی و بازیابی کامل داده‌ها به‌صورت فایل JSON |

### امکانات نسخهٔ ۲ 🚀

| بخش | توضیح |
|---|---|
| 🌐 **قیمت‌خوانی آنلاین** | دریافت قیمت طلا (۱۸/۲۴، مثقال، انس)، نقره، انواع سکه و ارزها (دلار، یورو، درهم، لیر…) مستقیم روی گوشی از API عمومی TGJU — **بدون هیچ سرور میانی**؛ آفلاین هم همه‌چیز کار می‌کند و قیمت‌ها قابل ویرایش دستی هستند |
| 📜 **ثبت سند مرکزی** | بیش از ۴۰ نوع سند با فرم پویا: خرید/فروش/ورود/خروج و طلب/بدهی برای **آبشده و متفرقه (با عیار)، سکه، شمش (تعدادی)، ارز، نقره و کارساخته** + درآمد/هزینه نقدی، ورود/خروج وجه نقد، درآمد/هزینه بانکی، دریافت/پرداخت مشتری به بانک، چک دریافتی/پرداختنی و تخفیف‌ها |
| 🗂 **دفتر اسناد** | لیست آخرین اسناد بر اساس زمان ثبت/به‌روزرسانی، ردیف شرح هر سند، استعلام با شماره/تاریخ/شرح، حذف سند با برگشت کامل همهٔ اثرات |
| 📄 **چک‌ها** | دفتر چک با وضعیت (باز/پاس‌شده/برگشتی/ابطال) و انتقال خودکار به بانک هنگام پاس شدن |
| 🏦 **بانک‌ها** | موجودی هر حساب بانکی + مجموع، در تراز کل |
| ⚖️ **دارایی‌ها و تراز** | تراز صندوق و بانک‌ها، آبشده **تکی بر اساس عیار**، موجودی سکه/شمش/ارز/نقره/کارساخته، چک‌های باز |
| 👥 **حساب‌ها (کد حساب + گروه حساب)** | ثبت/ویرایش مشتری با کد حساب یکتا و گروه حساب، فیلتر از کد تا کد / تلفن / نام، **مانده چند مشتری با تفکیک گروه حساب** و **مانده یک مشتری تا تاریخ مشخص**؛ مانده به دو واحد **گرم و سوت** + **تومان و ریال** |
| 🗄 **کدینگ‌ها** | لیست نام‌ها: گروه‌های حساب، ری‌گیری‌ها، ارزها، سکه‌ها، شمش‌ها، بانک‌ها، کارهای ساخته، نقره — افزودن/ویرایش/حذف با کنترل ارجاع |
| 🏷 **اتیکت** | کد کار، نام، وزن (گرم و سوت)، مزنه، عکس، RFID، **وضعیت (موجود/فروخته‌شده/خارج)**؛ جستجو/فیلترهای متنوع، به‌روزرسانی مزنه، کارت اتیکت با **بارکد Code-128**، **ثبت سند خرید/فروش/ورود/خروج اتیکت** (حذف خودکار RFID هنگام خروج)، **دفتر تگ‌های RFID با جستجو و ارسال لیست** |

## 📱 نصب

فایل APK آماده در پوشهٔ [`publish/`](publish) قرار دارد:

```
publish/Talayar-GoldAccounting-v2.1.apk
```

کافی است آن را روی گوشی اندرویدی (Android 7 به بالا) کپی و نصب کنید (گزینهٔ «نصب از منابع ناشناخته» را اجازه دهید).

> 🔖 راهنمای سریع پس از نصب: ابتدا از «قیمت‌های بازار» قیمت امروز را دریافت (یا در «نرخ طلا» دستی ثبت) کنید، سپس در «کدینگ‌ها» فهرست‌های پایه را تکمیل کنید و از «ثبت سند جدید» یا «فاکتور جدید» کار را شروع کنید.

## 🛠️ ساخت از سورس

این پروژه **بدون اندروید استودیو و بدون Gradle** با یک زنجیرهٔ ابزار سبک ساخته می‌شود (جزئیات در `TOOLCHAIN.md`):

```bash
bash build.sh
```

خروجی مستقیم به `publish/` کپی می‌شود. زنجیرهٔ ساخت:

1. **aapt2** — کامپایل و لینک منابع
2. **janino** — کامپایل جاوا (به‌جای javac)
3. **D8/R8** — تولید classes.dex
4. **apksigner** — امضای v2/v3

## 🗂️ ساختار مخزن

```
├── AndroidManifest.xml     # مانیفست (مجوز اینترنت فقط برای قیمت‌خوانی مستقیم)
├── res/                    # منابع (استرینگ/رنگ/آیکون)
├── assets/fonts/           # فونت وزیرمتن
├── android/src/main/java/com/talayar/app/   # ۳۱ کلاس جاوا
├── build.sh                # اسکریپت ساخت
├── TOOLCHAIN.md            # مستندات زنجیرهٔ ابزار
└── publish/                # APK آمادهٔ نصب
```
