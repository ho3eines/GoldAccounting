# طلایار 🪙⚖️ — حسابداری طلافروشی

![طلایار](docs/banner.png)

اپلیکیشن اندرویدی **حسابداری کامل طلافروشی** — کاملاً **فارسی و راست‌به‌چپ**، با ظاهری مدرن و لوکس (تم تیره + طلایی)، و کاملاً **آفلاین**: همه‌چیز داخل خود گوشی ذخیره می‌شود و **هیچ سرور میانی نیست**. دریافت قیمت‌های بازار هم (در صورت تمایل) **مستقیم از خود گوشی** از یک API عمومی انجام می‌شود.

### نسخهٔ وب — SQL Server (DB-First) 🗄️ + PWA 📱 + ریسپانسیو

پنل وب با **SQL Server** و به‌صورت کامل **DB-First** کار می‌کند:

- 🗄️ **پایگاه‌داده**: SQL Server — ساختار دیتابیس از اسکریپت‌های TSQL ساخته می‌شود (بدون EF Migrations و بدون `EnsureCreated`)
- 📜 **سیستم اسکریپت‌های TSQL (Resource Runner)**:
  - پوشهٔ `GoldAccounting.Server/wwwroot/resources`
  - فرمت نام فایل: `[DateTime]_[Create|alter]_[Tb|Sp|Fn]_[Name].sql` — مثال: `20260801_100000_Create_Tb_Customers.sql`
  - در هنگام راه‌اندازی، همهٔ اسکریپت‌های **اجرانشده** به ترتیب تاریخ اجرا می‌شوند و نتیجه در جدول **`dbo.Resources`** ثبت می‌شود:
    `Id, FileName, Success, ExecuteTime, ExecuteMs, ErrorText`
  - فایل‌هایی که قبلاً در جدول `Resources` ثبت شده‌اند **دیگر اجرا نمی‌شوند** (ضدتکرار)
  - صفحهٔ مدیریت: `/resources` (وضعیت فایل‌ها + تاریخچهٔ اجرا + دکمهٔ اجرای اسکریپت‌های جدید)
- 🔌 **راه‌اندازی**: کانکشن‌استرینگ در `appsettings.json` → `ConnectionStrings:DefaultConnection`
  ```json
  "DefaultConnection": "Server=.;Database=TalayarDb;Trusted_Connection=True;TrustServerCertificate=True;MultipleActiveResultSets=true"
  ```
  اگر دیتابیس وجود نداشته باشد، هنگام اجرا ساخته می‌شود و سپس اسکریپت‌ها اجرا می‌شوند.
- 📱 **PWA**: `manifest.webmanifest` + `sw.js` (کش هوشمند) + آیکون‌ها — قابل نصب روی موبایل/دسکتاپ، نوار ناوبری پایین موبایل، نصب با دکمهٔ «نصب»
- 🎨 **ریسپانسیو**: سایدبار چسبان دسکتاپ، دراور موبایل، جدول‌های اسکرول‌افقی، ناوبری پایین موبایل، safe-area
- ✨ **UI/UX Pro Max**: تم تیره-طلایی لوکس، انیمیشن‌های نرم، فوکوس قابل‌دسترس، اسکرول‌بار سفارشی، حالت کاهش حرکت

> راهنمای افزودن اسکریپت جدید: فایل را با فرمت نام استاندارد در `wwwroot/resources` بگذارید و دکمهٔ «اجرای اسکریپت‌های جدید» را در صفحهٔ `/resources` بزنید (یا سرور را ری‌استارت کنید). اسکریپت‌های ناموفق با خطای ذخیره‌شده در جدول مشخص می‌شوند و با حذف سطرشان از جدول، دوباره اجرا می‌شوند.

### 🍔 منوی همبرگری + 🛒 فروشگاه آنلاین (قیمت‌گذاری زنده)

- **منوی همبرگری**: دکمهٔ همبرگری در هدر (همهٔ سایزها) یک منوی کشویی حرفه‌ای باز می‌کند شامل:
  - کارت اطلاعات کاربر (آواتار، نام، نام کاربری، نقش، وضعیت اتصال)
  - نرخ لحظه‌ای طلا و تراز صندوق
  - نوبار کامل با دسته‌بندی (عملیات اصلی، فروشگاه، مدیریت، تحلیل و سیستم)
  - دکمهٔ تنظیمات و ورود/خروج
### 📖 راهنمای کامل استفاده (برای تازه‌کارها)

- **اندروید**: فایل `android/assets/usage_manual.html` (که قبلاً وجود نداشت و دکمهٔ راهنما خراب بود) با ۲۵ بخش کامل ساخته شد — با تم تیره-طلایی، فهرست، واژه‌نامه و آموزش قدم‌به‌قدم؛ در `bash build.sh` به‌صورت خودکار داخل APK می‌رود.


صفحهٔ `/guide` یک راهنمای کامل و ساده برای کسانی است که با سیستم آشنا نیستند:

- **شروع سریع**: اولین قدم‌ها برای راه‌اندازی و کار با برنامه
- **واژه‌نامهٔ کامل**: معنی سادهٔ همهٔ اصطلاحات (عیار، اجرت، رسوب، سوت، مانده، بدهکار/بستانکار، اتیکت، بارکد و…)
- **آموزش ۲۶ بخش** با زبان ساده: هر بخش شامل «این بخش چیست؟»، «اصطلاحاتش»، «نحوهٔ استفاده قدم‌به‌قدم» و «نکته‌ها»
- جستجوی سریع در راهنما + فهرست کناری + دسترسی از منوی همبرگری (بخش «راهنما») و دکمهٔ 📖 در هدر

### 🍔 منوی همبرگری + 🛒 فروشگاه آنلاین (قیمت‌گذاری زنده)

- **فروشگاه آنلاین** (`/shop`):
  - قیمت هر کالا بر اساس **نرخ روز طلا** به‌صورت زنده محاسبه می‌شود (طلا + اجرت + سنگ + مالیات)
  - اگر نرخ امروز ثبت شده باشد: نشان «✓ قیمت‌ها با نرخ امروز محاسبه شده‌اند» — در غیر این صورت هشدار «نرخ امروز ثبت نشده» نمایش داده می‌شود
  - جستجو، فیلتر بر اساس عیار، مرتب‌سازی (جدیدترین/ارزان‌ترین/گران‌ترین/نام)
  - صفحهٔ جزئیات محصول (`/shop/{id}`) با جدول قیمت و فرم «درخواست خرید»
  - درخواست‌ها در جدول `ShopRequests` ذخیره و در `/shop/requests` با وضعیت (جدید/در حال پیگیری/انجام‌شده/لغو) مدیریت می‌شوند

### پنل وب کامل (Blazor Server) 🌐

همهٔ بخش‌های عملیاتی برنامه در پنل وب `GoldAccounting.Server` هم پیاده شده‌اند (نه فقط مشاهده):

| بخش | آدرس |
|---|---|
| 🪙 نرخ روز طلا (ثبت، معادل‌ها، نمودار، تاریخچه) | `/rates` |
| 🌐 قیمت‌های بازار (دریافت آنلاین TGJU/BrsApi از سمت سرور + دستی) | `/prices` |
| 🧾 صدور فاکتور فروش جدید (انبار/دستی، اجرت، مالیات، طلا با رسوب، نسیه) | `/invoices/new` |
| 👁 مشاهدهٔ فاکتور + کپی متن + ابطال با سند معکوس | `/invoices/{id}` |
| 📦 اجناس و انبار (افزودن/ویرایش/حذف + ارزش روز) | `/items` |
| 👥 حساب‌ها/مشتریان (کد حساب، گروه، مانده چند مشتری تا تاریخ) | `/customers` |
| 👤 پروندهٔ مشتری (مانده نقدی/طلایی/دارایی، دریافت وجه/طلا، گردش) | `/customers/{id}` |
| 💰 صندوق (واریز/برداشت + تراکنش‌ها) | `/cash` |
| ⚖️ طلای آب‌شده (ورود/خروج دستی، تفکیک عیار، ارزش روز) | `/gold` |
| 🛍️ خرید طلای کارکرده (نرخ پیشنهادی، پرداخت نقد/به حساب) | `/buy` |
| 📜 ثبت سند مرکزی (۴۲ نوع سند با فرم پویا) | `/docs/new` |
| 🗂 دفتر اسناد (استعلام، حذف با برگشت کامل اثرات) | `/docs` |
| 💳 چک‌ها (پاس/برگشت/ابطال با انتقال خودکار به بانک) | `/checks` |
| 🏦 بانک‌ها (افزودن، موجودی، واریز/برداشت) | `/banks` |
| ⚖️ دارایی‌ها و تراز (صندوق، بانک، آب‌شده تکی، سکه/شمش/ارز/نقره، چک باز) | `/assets` |
| 🗄 کدینگ‌ها (۸ بخش با کنترل ارجاع) | `/defs` |
| 🏷 اتیکت‌ها (لیست/افزودن/ویرایش + کارت بارکد Code-128) | `/etikets` و `/etikets/{id}` |
| 📊 گزارش‌ها (امروز/ماه، موجودی، نقدینگی، گردش) | `/reports` |
| ⚙️ تنظیمات و پشتیبان‌گیری (بکاپ JSON سازگار با اندروید) | `/settings` |

پشتیبان‌گیری از پنل وب فرمتی مشابه بکاپ اندروید دارد (`api/backup/download` و `api/backup/restore`) و فایل‌های دو طرف قابل بازیابی متقابل هستند.

| 🗄 **کدینگ‌ها** | لیست نام‌ها: گروه‌های حساب، ری‌گیری‌ها، ارزها، سکه‌ها، شمش‌ها، بانک‌ها، کارهای ساخته، نقره — افزودن/ویرایش/حذف با کنترل ارجاع |
| 🏷 **اتیکت** | کد کار، نام، وزن (گرم و سوت)، مزنه، عکس، RFID، **وضعیت (موجود/فروخته‌شده/خارج)**؛ جستجو/فیلترهای متنوع، به‌روزرسانی مزنه، کارت اتیکت با **بارکد Code-128**، **ثبت سند خرید/فروش/ورود/خروج اتیکت** (حذف خودکار RFID هنگام خروج)، **دفتر تگ‌های RFID با جستجو و ارسال لیست** |

## 📱 نصب

فایل APK آماده در پوشهٔ [`publish/`](publish) قرار دارد:

```
publish/Talayar-GoldAccounting-v4.0.apk
```

کافی است آن را روی گوشی اندرویدی (Android 7 به بالا) کپی و نصب کنید (گزینهٔ «نصب از منابع ناشناخته» را اجازه دهید).

> ⚠️ اگر نسخهٔ ۱/۲/۳ را نصب دارید: کلید امضای نسخه‌های قبلی در دسترس نبود و این بیلد با **کلید امضای جدید** تولید شده و ارتقای مستقیم (نصب روی نسخهٔ قدیمی) ممکن نیست. ابتدا از تنظیمات نسخهٔ قدیمی **بکاپ** بگیرید، نسخهٔ قدیمی را حذف کنید، نسخهٔ ۴ را نصب کنید و بکاپ را **بازیابی** کنید. (راهنمای کامل در `publish/README-fa.md`)

> 🔖 راهنمای سریع پس از نصب: ابتدا از «قیمت‌های بازار» قیمت امروز را دریافت (یا در «نرخ طلا» دستی ثبت) کنید، سپس در «کدینگ‌ها» فهرست‌های پایه را تکمیل کنید و از «ثبت سند جدید» یا «فاکتور جدید» کار را شروع کنید.

## 🛠️ ساخت از سورس

این پروژه **بدون اندروید استودیو و بدون Gradle** با یک زنجیرهٔ ابزار سبک ساخته می‌شود (جزئیات در `TOOLCHAIN.md`):

```bash
bash build.sh
```

خروجی مستقیم به `publish/` کپی می‌شود. زنجیرهٔ ساخت:

1. **aapt2** — کامپایل و لینک منابع
2. **janino** — کامپایل جاوا (به‌جای javac)
3. **D8/R8** — تولید classes.dex
4. **apksigner** — امضای v2/v3

## 🗂️ ساختار مخزن

```
├── AndroidManifest.xml     # مانیفست (مجوز اینترنت فقط برای قیمت‌خوانی مستقیم)

├── assets/fonts/           # فونت وزیرمتن
├── android/src/main/java/com/talayar/app/   # ۳۱ کلاس جاوا
├── build.sh                # اسکریپت ساخت
├── TOOLCHAIN.md            # مستندات زنجیرهٔ ابزار
└── publish/                # APK آمادهٔ نصب
```
