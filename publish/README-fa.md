# 📱 نصب و راهنمای استفاده — طلایار نسخهٔ ۲٫۱

## فایل نصب

**`Talayar-GoldAccounting-v2.1.apk`** را روی گوشی کپی کنید و اجراش کنید. اگر گوشی هشدار «نصب از منابع ناشناخته» داد، اجازهٔ نصب را فعال کنید (فقط برای همین یک‌بار).

- حداقل اندروید: **7.0 (API 24)**
- مجوزها: فقط **اینترنت** — و آن هم فقط برای «دریافت اختیاری قیمت‌های بازار» مستقیم از API عمومی. **هیچ سرور میانی وجود ندارد** و بدون اینترنت هم همهٔ امکانات برنامه کاملاً آفلاین کار می‌کنند.
- اگر نسخهٔ ۱ را دارید، نسخهٔ ۲ روی همان نصب می‌شود و **داده‌هایتان حفظ می‌ماند** (ارتقای خودکار پایگاه‌داده).

## شروع سریع 🚀

1. **قیمت‌های بازار** ← دکمهٔ «دریافت قیمت‌ها از اینترنت» (یا دستی وارد کنید). نرخ دفتری طلای ۱۸ خودکار به‌روز می‌شود.
2. **کدینگ‌ها** ← گروه‌های حساب، نوع سکه/شمش/ارز/نقره، بانک‌ها و کارهای ساخته را بسازید (موارد پیش‌فرض از قبل هستند).
3. **حساب‌ها / مشتریان** ← مشتری‌ها را با **کد حساب** و **گروه حساب** ثبت کنید.
4. **ثبت سند جدید** ← هر رویداد مالی: خرید/فروش آبشده، سکه، شمش، ارز، نقره، کارساخته؛ ورود/خروج؛ طلب/بدهی؛ درآمد/هزینه نقدی و بانکی؛ چک؛ تخفیف.
5. **فاکتور جدید** ← فروش اجناس با اجرت، سنگ، مالیات و تسویهٔ چندبخشی.
6. **داشبورد و دارایی‌ها** ← تراز صندوق و بانک، آبشده تکی بر عیار، موجودی سکه/شمش/ارز/نقره/کارساخته و چک‌های باز.

## بخش‌های کلیدی 🧭

- **اسناد** ← لیست آخرین اسناد (بر اساس زمان ثبت یا به‌روزرسانی)، ردیف شرح، استعلام با شماره/تاریخ/شرح، حذف سند با **برگشت کامل اثرات**.
- **چک‌ها** ← پاس شدن چک مبلغ را خودکار به/از بانک منتقل می‌کند؛ برگشت خوردن اثر تسویه را برمی‌گرداند.
- **حساب‌ها** ← فیلتر نام/تلفن و «از کد تا کد»؛ دکمهٔ «مانده چند مشتری» گزارش تجمیعی با تفکیک گروه حساب می‌دهد؛ در پروندهٔ هر مشتری: مانده نقدی (تومان و ریال)، طلایی (گرم و سوت)، سکه/شمش/ارز/نقره/کارساخته + **مانده تا تاریخ مشخص**.
- **اتیکت‌ها** ← کد کار، نام، وزن، مزنه و عکس؛ فیلترهای متنوع (کد/نام/وزن/بازهٔ شناسه/وضعیت: موجود، فروخته‌شده، خارج‌شده)؛ به‌روزرسانی مزنه؛ ساخت **کارت اتیکت با بارکد** و اشتراک آن.
- **سند اتیکت** ← خرید/فروش/ورود/خروج اتیکت از «ثبت سند» یا دکمهٔ مستقیم در پروندهٔ اتیکت؛ با فروش/خروج، **RFID به‌صورت خودکار حذف** و موجودی کارساختهٔ وزنی اصلاح می‌شود؛ با حذف سند، اتیکت به با«موجود» برمی‌گردد.
- **تگ‌های RFID** ← از «اتیکت‌ها ← 📡 تگ‌های RFID» همهٔ تگ‌های خوانده‌شده را ببینید، جستجو کنید، و **لیست را ارسال** کنید؛ مشخصات هر تگ (با تصویر) در پروندهٔ اتیکت است.

## نکته‌ها 💡

- برای دیدن پروندهٔ مشتری روی نامش بزنید؛ «دریافت وجه/طلا» و «سند جدید برای این مشتری» آنجاست.
- اگر سندی اشتباه شد، از «اسناد» آن را حذف کنید — همهٔ اثرات (صندوق، بانک، آبشده، حساب مشتری، سکه/ارز و چک) برگردانده می‌شود.
- هر چند وقت یک‌بار از **تنظیمات ← ایجاد فایل بکاپ** خروجی بگیرید تا داده‌ها محفوظ بماند (حالا شامل اسناد، اتیکت‌ها و چک‌ها هم می‌شود).
- آدرس API قیمت‌ها در **تنظیمات** قابل تغییر است.
