# 📱 نصب و راهنمای استفاده — طلایار

## فایل نصب

**`Talayar-GoldAccounting-v1.0.apk`** را روی گوشی کپی کنید و اجراش کنید. اگر گوشی هشدار «نصب از منابع ناشناخته» داد، اجازهٔ نصب را فعال کنید (فقط برای همین یک‌بار).

- حداقل اندروید: **7.0 (API 24)**
- مجوزها: **هیچ‌کدام** — حتی اینترنت! برنامه کاملاً آفلاین است و داده‌ها فقط روی گوشی شما می‌ماند.

## شروع سریع 🚀

1. **نرخ طلا** ← نرخ امروز هر گرم طلای ۱۸عیار را ثبت کنید (معادل‌های ۲۴ تا ۱۴ عیار و مثقال خودکار محاسبه می‌شود).
2. **اجناس و انبار** ← اجناس موجود را اضافه کنید (نام، عیار، وزن، نوع اجرت).
3. **مشتریان** ← مشتری‌های ثابت را ثبت کنید.
4. **فاکتور جدید** ← فروش را ثبت کنید؛ اجرت، سنگ، مالیات و مانده خودکار محاسبه می‌شود و جنس از انبار کم می‌شود.
5. **داشبورد** ← هر روز خلاصهٔ کسب‌وکار: صندوق، موجودی طلا، طلب‌ها و فروش امروز.

## نکته‌ها 💡

- برای دیدن سند مشتری روی نامش بزنید؛ «دریافت وجه» یا «دریافت طلا» مانده را کم می‌کند.
- در لیست صندوق و طلا، با **نگه‌داشتن** روی هر تراکنش می‌توانید آن را حذف کنید.
- اگر فاکتوری اشتباه شد، از صفحهٔ فاکتور «ابطال فاکتور» بزنید — جنس به انبار برمی‌گردد و اسناد معکوس ثبت می‌شود.
- هر چند وقت یک‌بار از **تنظیمات ← ایجاد فایل بکاپ** خروجی بگیرید تا داده‌ها محفوظ بماند.
